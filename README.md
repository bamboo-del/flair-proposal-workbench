# Flair Proposal · 户外媒体提案台

一个给提案团队使用的在线多项目工作台。项目覆盖需求假设、点位与媒体、镜像数据、计价、排期、执行证据和客户交付。客户可在网页查看固定版方案与三档预算。

## 启动

需要 Node.js 24。复制 .env.example 为 .env，设置 ADMIN_USER 和至少 12 个字符的 ADMIN_PASSWORD，然后运行 npm start。浏览器访问 http://127.0.0.1:3000。管理员只在空数据库时创建。运行 npm test 验证计算、导入、浏览器页面脚本和服务端流程。

## 实际使用

1. 管理员加入团队成员，分配编辑或只读权限。
2. 新建业务项目，录入匿名或获授权的客户名称，填写七要素假设书和目标商圈。
3. 在媒体工作台导入红豆格式库存和大数据平台覆盖结果。在计价页录入适用刊例版本、发布费上下限、折扣和制作费。
4. 查看覆盖与选线理由、库存档期与空位、预算差异、缺面积待办和排期。保存后可回看镜像批次。
5. 录入夜间容量、停工日期、缓冲与监测口径。补齐七要素后生成并预览客户版。只读链接指向固定版本，可设有效期和撤回。上刊、下刊、结案和异常附件保存在执行与监测页。

创建练习项目时可主动选择合成数据。业务项目从空数据开始，刊例未配置时不出价。红豆和覆盖导出走私有工作区。开源仓库只含测试用例、代码和合成数据。
