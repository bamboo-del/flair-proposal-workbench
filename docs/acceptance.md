# 主办方口径与验收

依据为 INTERCITY HACK 湖州场《好提案的标准与需求定义（学生版）》，2026-11-21。以下为开发摘要。

## 评分与硬规则

| 维度 | 分数 | 产品应提供的证据 |
| --- | ---: | --- |
| 业务价值 | 30 | 把客户的业务目标映射到媒体组合与取舍，并逐条回应假设书 |
| 完成度与可用性 | 25 | 输入到客户提案全链跑通，现场更换行业、媒体、档期和预算 |
| AI 应用质量 | 20 | AI 参与调研、决策辅助、生成或校验，结果可追溯到输入和证据 |
| 行业专业度 | 15 | 按档期核对空位、刊例和执行限制，明确监测与异常处理 |
| 演示表达 | 10 | 现场讲清一条选点证据和一次改预算取舍 |

缺少端到端链路无法参评。现场无法真实运行时，完成度记零。公开演示中的真实客户名或真实成交价每处扣 10 分。**不交假设书或方案未逐条回应时，业务价值最多 18／30。**

## Campaign 假设书

| 要素 | 保存字段与提案回应 |
| --- | --- |
| 客户与品牌 | 行业、匿名品牌类型与规模，阐明选点适配 |
| 生意目标 | 明确商业问题，说明媒体策略如何支持 |
| Campaign 主目标 | 认知、到店、促销、拉新选一项，由组合和指标回应 |
| 目标人群 | 人群画像与活动区域，用门店、地标和覆盖证据解释 |
| 时间与预算 | 2027 起止档期、预算档、范围价格与执行缓冲 |
| 媒体范围 | 公交车身、地铁出入口或组合，说明主次与互补 |
| 成功衡量 | KPI 口径及数据来源，附上刊、下刊、结案的监测交付 |

## 现场回归

1. 新建两个不同行业的匿名项目，各自保存、刷新和恢复版本。两者的假设书、点位、快照和报价独立。
2. 展示一条完整链路。门店／地标 → 查询半径与覆盖结果 → 公交线路／地铁出入口 → 红豆目标区间与空位 → 刊例、制作费和排期。重复命中的门店只算一次。
3. 在同一方案切 **100 ↔ 200 ↔ 500 万**，展示哪些资源保留、变动及哪些门店受影响。总价上沿受预算和执行缓冲约束。
4. 更换档期并导入旧快照、目标区间快照及零空位资源。旧档期待重查，零空位不可选。地铁缺面积为待核，补面积后重新计算。
5. 排期能解释夜间施工批次、单夜容量、天气停工和缓冲。异常登记支持备选点位、重排，以及按项目合同记录「误一补二」等处理口径。
6. 客户版 HTML 可现场互动，显示提案响应、覆盖与触达估算口径、刊例／折扣／制作与执行费、上下刊照片与结案要求。估算指标与实际转化分别呈现。
